# Limoli Design portfolio

Static portfolio site for Joe Limoli / Limoli Design. Plain HTML, CSS and JS. No build step.

- `index.html` is a copy of `portfolio.html` (home)
- One HTML file per project
- `assets/` holds all images, video, fonts and the resume PDF at full quality

## Preview locally
Run `python3 -m http.server 8000` in this folder, then open http://localhost:8000

## Publish
Netlify: Add new site > Import from Git > pick this repo. No build command. Publish directory: the repo root.
